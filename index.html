About this dossier

Built as a compilation tool for Reading in Philippine History coursework. The front end is plain HTML, CSS, and JavaScript; entries and files are stored in a Postgres database and file bucket on Supabase, gated by Supabase Auth and Row Level Security so that only the signed-in owner can add or remove entries while anyone with the link can browse and download them.
